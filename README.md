EMBERLINE — Foundry Yards: a round-based tactical FPS in three.js. Two teams fight short rounds in a foundry yard — eliminate the other team or plant/defuse the charge — earn money between rounds to buy weapons, against bots, offline in a browser.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
